# 🚗 Waze User Churn Prediction App 📊

Welcome to the **Waze Churn Prediction** project! 🎉 This interactive Machine Learning web application is designed to analyze user behavior and predict whether a Waze user will continue using the app (Retained 🟢) or stop using it (Churned 🔴).

## 🌟 Overview
Using an advanced **XGBoost** model 🧠 trained on the Waze dataset, this app provides real-time predictions based on user activity metrics such as driving days 📅, total sessions 📱, and kilometers driven 🛣️.

## 🚀 Features
- **⚡ Real-Time Predictions:** Get instant results with just a click!
- **🎨 User-Friendly UI:** Built entirely with Streamlit for a clean, interactive experience.
- **🎯 High Accuracy:** Powered by a robust, fine-tuned Machine Learning model.
- **📱 Device Integration:** Accounts for different user devices (iPhone vs. Android).

## 🛠️ Technologies & Tools Used
- **Python** 🐍 - Core programming language
- **Streamlit** 👑 - For building the interactive web interface
- **XGBoost & Scikit-Learn** 🤖 - For model training and prediction
- **Pandas & NumPy** 🧮 - For data processing and manipulation
- **Joblib** 📦 - For saving and loading the trained model

## 💻 How to Use
1. Open the web app link 🌐
2. Enter the user's statistics in the provided fields (sessions, distance, etc.) ✍️
3. Select the device type 📱
4. Click on **"توقع حالة المستخدم"** 🔮
5. See the magic happen! ✨
